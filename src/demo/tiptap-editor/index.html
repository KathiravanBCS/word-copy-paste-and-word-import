TipTap Integration

A live, editable TipTap (ProseMirror) surface with a real Word list node in its schema, not a workaround bolted onto someone else's.

Fixture gallery Clipboard Lab RoosterJS Integration

This is a real TipTap/ProseMirror editor. Two custom node types, wordList and wordListItem (WordListNodes.ts), give the schema itself a slot for Word's numbering declaration — level format, level text, list identity — so a marker's text is always computed from live document position, in any Word number format (roman, alpha, ordinal, any composite mix), not read once and left static. WordClipboardExtension.ts is the paste handler.

Paste real content from Microsoft Word below, or use Paste a fixture to simulate one. Press Enter at the end of any numbered or bulleted item — including a composite level like "1.1" or "1.1.1" — and the next one is numbered correctly immediately, no delay, no workaround: see docs/RICH-TEXT-EDITOR.md for how this differs from the RoosterJS integration.
