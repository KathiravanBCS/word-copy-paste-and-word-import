RoosterJS Integration

A live, editable RoosterJS surface whose paste handling is this engine, not RoosterJS's own.

Fixture gallery Clipboard Lab TipTap Integration

This is a real RoosterJS editor — createEditor() from the roosterjs package, unmodified. The only addition is one plugin, WordClipboardEnginePlugin, which intercepts RoosterJS's own BeforePasteEvent and hands Word payloads to this engine instead of RoosterJS's built-in Word-paste handling. Everything else about the editor — typing, undo, the toolbar commands below, non-Word paste — is exactly what RoosterJS already does.

Paste real content from Microsoft Word below, or use Paste a fixture to simulate one without a live Word document. Then try editing it: click right before a bullet or number and press Backspace — the marker comes out as a whole unit, never one corrupted character at a time. That is the difference this page exists to demonstrate; see docs/RICH-TEXT-EDITOR.md.
